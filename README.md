# 📊 CSV 批次轉 Excel 轉換器（CSV to Excel Converter）

一款專為日常資料處理設計的 Python 桌面小工具，解決手動開啟 CSV 常見的**中文亂碼**、**前導零消失**以及**欄寬擠壓**等痛點，並支援多檔案一鍵合併成單一 Excel 報表。

---

## ✨ 核心功能與亮點

* **📁 視覺化資料夾掃描與勾選**：指定來源資料夾後自動列出所有 `.csv` 檔案，支援滑鼠滾輪捲動、斑馬紋交錯底色，並提供「全選 / 取消全選」與即時勾選計數。
* **📑 雙模式輸出（預設合併模式）**：
  * **合併模式（預設勾選）**：將勾選的多個 CSV 合併為單一 `.xlsx` 檔案（自動加上時間戳記防覆蓋），每個 CSV 各自成為獨立的工作表（Sheet），並自動清理 Excel 禁用字元與 31 字元名稱上限。
  * **獨立模式（取消勾選）**：將勾選的每個 CSV 各自轉換為獨立的 `.xlsx` 檔案。
* **🛡️ 資料防呆與自動排版**：
  * **自動編碼相容**：優先以 `UTF-8-SIG` 讀取，若遇傳統 Excel 匯出檔則自動切換為 `Big5 / CP950`，徹底告別亂碼。
  * **保留前導零**：所有欄位強制以純文字（`dtype=str`）讀取，確保店號（如 `012345`）、電話號碼與郵遞區號開頭的 `0` 完整保留。
  * **智慧自動欄寬與凍結首列**：自動凍結標題列（`A2`）、套用深色標題橫幅樣式，並依中英文字元寬度比例自動調整所有欄寬。
* **📂 自動歸檔與開啟**：所有轉出檔案統一儲存於執行檔（`.py` 或 `.exe`）同層目錄下的 `output` 資料夾，轉換完成後自動彈出該資料夾方便檢視。

## 🛠️ 環境需求與安裝

本工具使用 Python 3 開發，執行前請先安裝以下兩個資料處理套件（`tkinter` 為 Python 內建標準庫，無需額外安裝）：

```bash
pip install pandas openpyxl
```

---

## 🚀 使用方式

1. **啟動程式**：
   在終端機或編輯器中執行主程式：
   ```bash
   python csv_to_excel.py
   ```
2. **選擇來源目錄**：
   點擊頂部 **「📂 選擇 CSV 資料夾」** 按鈕，選取存放 CSV 檔案的資料夾。
3. **勾選目標檔案與模式**：
   * 系統預設勾選所有掃描到的 CSV 檔案，可依需求單獨勾選或使用 **「✔ 全選」/「✖ 取消全選」** 調整。
   * 右上方 **「📑 合併模式（同檔多工作表）」** 預設為勾選；若希望每個 CSV 各自產出獨立 Excel 檔，取消勾選即可。
4. **一鍵轉換**：
   點擊底部 **「🚀 立即轉換為精美 Excel」**，完成後系統將自動開啟 `output` 資料夾。

## 🔧 程式碼架構與自訂微調指南

本程式採用**純函式（Procedural）**設計，無複雜的類別繼承結構，方便日後直接開啟修改：

| 欲調整項目 | 對應位置 / 函式名稱 | 修改說明 |
| :--- | :--- | :--- |
| **介面色彩主題** | 程式頂部 `THEME` 字典 | 修改對應的 Hex 色碼（如 `primary`、`convert`）即可更換按鈕與背景配色。 |
| **欄位緩衝寬度** | `style_worksheet()` | 找到 `max_length + 4`，調大或調小數字即可控制欄寬的左右留白空間。 |
| **合併檔案名稱** | `start_convert()` | 找到 `excel_filename = f"合併報表_{timestamp}.xlsx"`，可自訂輸出檔名前綴。 |
| **標題列樣式** | `style_worksheet()` | 修改 `header_fill`（底色）與 `header_font`（字體顏色與大小）。 |
