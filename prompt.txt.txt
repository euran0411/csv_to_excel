請幫我用 Python 寫一個「CSV 批次轉 Excel 桌面小工具」，具體需求與規範如下：

1. 程式架構與寫作風格：
   - 採用純函式（Procedural）寫法，不使用 class 類別設計，也避免艱澀語法，確保程式碼好閱讀、好維護。
   - 使用 Tkinter 製作圖形化介面，搭配 pandas 與 openpyxl 處理資料與排版。

2. 核心功能需求：
   - 選擇來源目錄：可點擊按鈕指定資料夾，自動掃描並列出該資料夾內所有的 .csv 檔案。
   - 清單勾選與控制：檔案清單支援滑鼠滾輪捲動、斑馬紋交錯底色，提供「全選 / 取消全選」按鈕，並即時顯示「總檔案數 / 已勾選數」。
   - 合併模式（預設勾選）：
     * 勾選時：將選取的多個 CSV 合併輸出為同一個 Excel 檔（檔名加上時間戳記防覆蓋），每個 CSV 各自成為一個獨立工作表（Sheet），並自動清理工作表名稱的禁用符號與 31 字元長度限制。
     * 取消勾選時：每個 CSV 各自轉換為獨立的 .xlsx 檔案。
   - 輸出路徑：自動儲存至「執行檔（.py 或打包後 .exe）所在目錄底下的 output 資料夾」（不存在則自動建立），轉換完成後自動彈出開啟該資料夾。

3. Excel 格式與防呆處理：
   - 編碼與防吃零：自動相容 UTF-8-SIG 與 Big5/CP950 編碼；所有欄位強制以字串（dtype=str）讀取，避免店號、電話或料號開頭的 0 消失。
   - 表格美化：凍結首列（A2）、標題列加上深色底白字加粗樣式，並依中英文字數比例自動適配所有欄位寬度。

4. 介面視覺設計（UI）：
   - 採用現代繽紛卡片式設計（Card Layout），去除生硬邊框（relief="flat"），將所有配色集中管理在頂部的 THEME 字典中。
   - 視窗開啟時強制置頂（lift + topmost）避免躲在編輯器後方。
